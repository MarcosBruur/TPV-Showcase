# Galería del sistema

[Volver a la presentación](../../README.md)

Cuatro pantallas de TPV configurado para una perfumería. Las imágenes documentan la interfaz; las funciones y reglas del sistema se explican en la documentación técnica.

## Punto de venta

Catálogo con fotografías, categorías, precios y stock disponible. El panel lateral reúne el ticket, los medios de pago, el importe recibido y el vuelto. En esta captura el ticket está vacío.

![Punto de venta con catálogo visual y ticket vacío](pos.png)

## Inventario

Listado de artículos con código, categoría, unidad, costo, precio de venta, stock y estado. Incluye búsqueda, filtros y acciones de mantenimiento.

![Inventario de artículos con precios, stock y acciones](inventario.png)

## Cobros

Listado de ventas registradas pendientes de cobro. Presenta vendedor, cliente, cantidad de artículos, importe y acciones para editar o cobrar cada operación.

![Ventas registradas pendientes de cobro](cobros.png)

## Caja y turnos

Historial con número de caja, operador, apertura, cierre, fondo inicial, ventas y gastos en efectivo. Permite observar saldos esperados, diferencias y estados de los turnos.

![Historial de turnos de caja y arqueo](caja.png)

Para destacar una nueva imagen en el README raíz, usar una referencia como assets/screenshots/dashboard.png una vez que el archivo exista. Desde esta galería, usar simplemente dashboard.png.

Mantener un tamaño consistente y texto legible. Las capturas actuales pesan menos de 300 KB cada una. Para la portada, una futura captura del punto de venta con artículos en el ticket mostraría mejor una operación en curso.

Antes de publicar, comprobar que la identidad comercial, los nombres y las operaciones visibles sean aptos para difusión. Consultar la [guía de privacidad](../../docs/SEGURIDAD.md). Para nuevas capturas, usar datos ficticios y evitar documentos fiscales reales.
